Cómo Funciona y Seguridad

🔒 100% Procesamiento del Lado del Cliente

Todo el procesamiento de archivos ocurre directamente en tu navegador usando JavaScript. Ningún dato se envía nunca a ningún servidor.

  • Archivos almacenados solo en RAM del navegador
  • Sin procesamiento del lado del servidor
  • Sin almacenamiento en la nube o bases de datos

🛡️ Seguridad de Datos

Tus datos sensibles están completamente seguros con múltiples capas de protección:

  • Sin solicitudes de red con datos de archivo
  • Auto-eliminado cuando se cierra la página
  • Sin registro o análisis de contenido

⚡ Cómo Funciona el Procesamiento

Comparación avanzada de archivos usando tecnologías web modernas:

  • API FileReader para acceso local a archivos
  • Librería XLSX.js para archivos Excel
  • Algoritmos inteligentes de coincidencia difusa

🔍 Ciclo de Vida de Datos

Transparencia completa en cómo se manejan tus datos:

  • Cargado → Procesado → Mostrado
  • Automáticamente eliminado al recargar
  • Sin almacenamiento permanente en ningún lugar
